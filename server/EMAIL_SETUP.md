# Подключение отправки Email в Tour Selection

## 1. Установить библиотеку на сервере

После обновления файлов проекта выполните в SSH:

```bash
cd /opt/tourboard/server
npm install
```

В `package.json` добавлена зависимость Nodemailer. Она нужна серверу для отправки сообщений по SMTP.

## 2. Настроить SMTP

Создайте конфигурационный файл, если его ещё нет:

```bash
cd /opt/tourboard/server
cp .env.example .env
nano .env
```

Вставьте пароль SMTP-почты `offers@tourboard.online` вместо `PUT_YOUR_SMTP_PASSWORD_HERE`. Остальные параметры для SpaceWeb:

```env
SMTP_HOST=smtp.spaceweb.ru
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=offers@tourboard.online
SMTP_PASS=ВАШ_ПАРОЛЬ_SMTP
SMTP_FROM=Tour Selection <offers@tourboard.online>
```

Сохраните файл: Ctrl+O, Enter, Ctrl+X. Не публикуйте `.env` и не вставляйте пароль в браузер или расширение. Сервер автоматически читает этот файл при запуске.

## 3. Перезапустить сервер

Перезапустите Tour Selection тем же способом, которым он сейчас запущен (systemd/PM2/ручной запуск). Если сервер работает через systemd, сначала найдите имя службы:

```bash
systemctl list-units --type=service | grep -i tour
```

Затем перезапустите найденную службу, например:

```bash
systemctl restart ИМЯ_СЛУЖБЫ
```

## 4. Отправить письмо

1. Войдите в Tour Selection под аккаунтом администратора или менеджера.
2. Откройте нужную подборку.
3. Нажмите «Отправить по Email».
4. Проверьте адрес, тему и содержимое письма (в том числе HTML-код, если редактировали его).
5. Нажмите «Отправить».

Успешная отправка отобразится в статусе окна. Ошибки SMTP будут показаны в этом же окне.

## Как настроена отправка

- From: `Tour Selection <offers@tourboard.online>` (можно переопределить переменной `SMTP_FROM`).
- Reply-To: Email организации из настроек админ-панели.
- BCC: Email организации, если включён флажок «Отправлять скрытые копии подборок на указанную почту».
- SMTP-пароль хранится только на сервере.
- При вставке изображения из файла редактор превращает его в MIME-вложение, чтобы изображение отображалось в письме.
