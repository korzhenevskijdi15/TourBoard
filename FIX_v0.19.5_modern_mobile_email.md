# v0.19.5 — Modern template mobile email layout

- Added mobile-specific CSS directly to the generated Modern email HTML, following the responsive email strategy used by the Strict template.
- On mobile, the header, contacts, manager details, offer cards, price block, CTA and footer use a fluid single-column layout.
- Images scale to the available width and long titles, descriptions, metadata and social links wrap instead of overflowing.
- The Modern desktop layout and its current desktop maximum width are unchanged.
- Checked JavaScript syntax with `node --check`.
