# Tour Selection — Delfin MVP 0.4

## Что добавлено
- Название подборки.
- Перемещение предложений вверх/вниз для изменения порядка.
- Удаление отдельных предложений и очистка текущей подборки с подтверждением.
- Сохранение текущей подборки в локальном хранилище Chrome.
- Восстановление последней сохранённой подборки.
- Экспорт JSON теперь включает название и массив предложений.

## Установка
Распакуйте архив и загрузите папку через `chrome://extensions` → «Загрузить распакованное расширение». Если расширение уже установлено из этой же папки, нажмите «Обновить» и перезагрузите вкладку Delfin-tour.

## Важно
Это версия 0.4: сохранение пока локальное в Chrome, не на сервере. Сохранённая подборка — один локальный снимок, который можно восстановить. Публичная ссылка, веб-кабинет и отправка клиенту будут реализованы на следующих этапах.

\n## 0.6.1 — сохранение в веб-кабинет
Кнопка «Сохранить в веб-кабинет» теперь синхронизирует текущую подборку с сервером. Повторное сохранение обновляет ту же подборку по serverCollectionId, не создавая дубль. Кнопка «Создать ссылку для клиента» использует ту же запись. «Очистить» начинает новую подборку и сбрасывает привязку к предыдущей, при этом уже опубликованная подборка в кабинете остаётся.


## Версия 0.7.0

Кнопка «Сохранить» отправляет подборку в веб-кабинет, сбрасывает локальные предложения и открывает страницу редактирования сохранённой подборки. Кнопка «Редактировать» удалена из расширения. После очистки следующий набор предложений создаёт новую подборку, а не перезаписывает предыдущую.

## Версия 0.8.20 — работа с production-сервером
- API расширения и кнопка «В личный кабинет» используют https://tourboard.online вместо localhost.
- После успешного сохранения подборка записывается на сервер, а локальный снимок остаётся в chrome.storage.local.
- Повторное сохранение уже созданной серверной подборки обновляет её по ID.
