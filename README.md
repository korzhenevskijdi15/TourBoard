## Авторизация и роли (0.14.6)

### Первичный запуск
- Запустите `server/start.bat`, затем откройте `/`.
- При первом запуске откроется форма создания единственного администратора.
- Логин: 3–40 символов, латинские буквы, цифры, `.`, `_`, `-`.
- Пароль: минимум 10 символов. Пароль хранится в виде scrypt-хеша, не в открытом виде.

### Роли
- **Администратор** — единственная учётная запись администратора; может создавать менеджеров, управлять всеми подборками, редактировать персональные настройки и настройки организации.
- **Менеджер** — имеет уникальный ID вида `M-XXXXXXXX`, привязан к ID администратора; может создавать и редактировать только свои подборки и менять свои персональные настройки. Раздел «Настройки организации» недоступен.

### Сессии и данные
- Вход через логин/пароль; сессия хранится в HttpOnly cookie (12 часов, обновляется при активности).
- Выход завершает текущую сессию.
- Подборки менеджеров сохраняют `ownerId`, `adminId` и `managerId`.
- Существующие подборки при первичном создании администратора закрепляются за ним, чтобы не потерять доступ.
- Клиентские страницы подборок остаются публичными; контакты менеджера берутся из персональных настроек владельца подборки, а данные организации — из настроек организации.
- Список менеджеров и их уникальные ID доступен администратору в разделе «Менеджеры».

**Важно:** сессии хранятся в памяти процесса и завершаются при перезапуске сервера. Для развёртывания в интернете рекомендуется использовать HTTPS и резервные копии `server/data.json`.
